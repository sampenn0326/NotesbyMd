    设入射激光沿 \(+z\) 传播，等离子体位于 \(z>0\) ，反射光返回 \(z<0\)

    \[ \omega _p^2 (r,z) = \frac{e^2 n_e(r,z)}{\varepsilon _0 m_e},\qquad n_c (\omega )=\frac{\varepsilon _0 m_e \omega ^2}{e^2} \]

    设频率为 \(\omega\) 对应的临界密度面为

    \[ z_c(r,\omega)= s(\omega)-\frac{r^2}{4f_g(\omega)} \]

    其中 \(s(\omega)\) 为顶点位置， \(f_g(\omega)\) 为几何焦距。若视其为真空中的理想反射镜，则平行光入射后的焦点为

    \[ Z_g(\omega)=s(\omega)-f_g(\omega) \]

    所以几何上不同频率对应不同焦点，这个条件相当于

    \[ \frac{dZ_g}{d\omega}= \frac{ds}{d\omega}-\frac{df_g}{\omega}\ne0 \]

    其中有位置带来的顶点部分和形状带来的焦距部分贡献。

    考虑如下分布，

    \[ n_e(r,z) =\frac{\varepsilon_0m_e}{e^2}a^2 \left( \frac{z}{1-r^2/b^2} \right)^2 \]

    其中 \(a\) 控制纵向密度梯度， \(b\)​ 控制横向弯曲程度。取 \(r=0\) ，得到轴上为密度二次上升

    \[ n_e(0,z)=\frac{\varepsilon _0m_e}{e^2}a^2z^2,\qquad \omega _p(0,z)=az \]

    另一方面，对任意特定频率，令 \(\omega _p(r,z_c) =\omega\) ，得到

    \[ z_c(r,\omega)=\frac{\omega}{a}\left( 1-\frac{r^2}{b^2} \right) \]

    对照前面的几何表达式，得到

    \[ s(\omega)=\frac{\omega}{a},\qquad f_g(\omega)=\frac{ab^2}{4\omega} \]

    所以，高频对应更深的轴上临界点，同时对应几何焦距更短的抛物面。在 \(z\) 轴上的焦点坐标

    \[ Z_g(\omega) =s(\omega)-f_g(\omega)=\frac{\omega}{a}-\frac{ab^2}{4\omega} \]

    先不考虑入射脉冲的啁啾情况，仅看不同频率的焦点分布，实际上就依赖于参数 \(a,b\) 的值。进一步可见，即便不考虑现实 \(a,b\) 参数的取值，也只能是高频 $\omega $ 的焦点更靠近靶一侧，即 \(Z_g(\omega)\) 一定随着 \(\omega\) 的上升而增大。那么，flying focus的焦点传播速度（包括大小和方向）就只能通过调节入射啁啾来控制。

    如果从一种几何射线光学角度来简化考虑，激光被抛物线反射传播到焦点，其几何距离相当于直线传播到准线位置，即

    \[ z=s(\omega)+f_g(\omega)=\frac{\omega}{a} + \frac{ab^2}{4\omega} \]

    这个值随 \(\omega\) 变化的单调性是不明朗的，而且实际上不能只算几何距离，而且要加上密度不均带来的光程/相位累积。

    固体表面的高次谐波、CHF脉络

    这是26年9月，调研一些等离子体边界对激光脉冲调制的文献时，记录一些推导和发展节点。

    1. 高次谐波辐射机制

    ROM

    设电子动量分成法向和切向两部分 \(p_n, p_\tau\) ，即便电子总速度可以始终很接近光速，但决定反射表面推进速度的是法向运动。

    \[ \beta _s = \frac{p_n}{\sqrt{m_e^2 c^2 +p_n^2 +p_{\tau }^2}} \]

    表面运动对应的 $\gamma $ 因子是

    \[ \gamma _s =\frac{1}{\sqrt{1-\beta_s^2}} = \sqrt{1+\frac{p_n^2}{m_e^2c^2+p_{\tau}^2}} \]

    这与电子的总 \(\gamma\) 因子

    \[ \gamma_e =\sqrt{1+\frac{p_n^2+p_{\tau}^2}{m_e^2c^2}} \]

    明显不同。如果 \(p_n,p_{\tau}\) 都很大、彼此同量级，那么

    \[ \gamma _e \ge 1,\qquad \gamma _s \sim O(1) \]

    这是因为电子虽然运动得很快，但是相当一部分速度沿着表面，法向速度并没有极其接近 \(c\) 。只有在某些时刻

    \[ p_{\tau}(t_g)=0,\qquad |p_n(t_g)|\ge m_e c \]

    ROM 和 CWE 是“强激光照射固体，形成过密等离子体表面”的情形下，两种不同的高次谐波产生机制，而且可以在同一次相互作用中同时存在。BGP 理论主要描述其中的相对论表面谐波，并不同时描述 CWE。

    ROM: relativistically oscillating plasma mirror

    CWE: coherent wake emission

    ROM 可以直观理解为：镜面迎着入射光快速运动时，反射波被压缩、频率提高；镜面周期性振荡，使反射波形发生周期性畸变，于是在频域出现高次谐波。

    为什么一定是谐波？镜面反射的多普勒频率上移本是连续频谱？

    多普勒频移本身并不保证产生整数次谐波。出现谐波，是因为镜面运动以及反射光的调制过程具有以激光周期为基准的重复性。 如果只发生一次快速反射或只产生一个短脉冲，完全可以得到连续的宽频谱。要区分瞬时频率和整个反射信号的傅里叶频谱。

    考虑以恒定速度迎向入射光的镜面。若镜面速度为 \(\beta c\)​ ，反射光频率为

    \[ \omega _r = \frac{1+\beta}{1-\beta}\omega _0 \]

    这个频率显然不一定是 \(\omega_0\) 的整数倍。因此，“发生了多普勒上移”与“产生了高次谐波”不是同一个命题。

    对于振荡镜面，\(\beta(t)\) 随时间变化，相应的瞬时频率也可以连续变化。但若这种调制每隔一个激光周期重复，整个反射信号仍然具有周期性，其傅里叶谱便只能出现在整数倍基频处。

    SRS&SBS

    受激拉曼散射（Stimulated Raman Scattering, SRS）和受激布里渊散射（Stimulated Brillouin Scattering, SBS）都是激光等离子体中最典型的三波耦合参量不稳定性。最直观的区别是：

    • SRS：激光把能量耦合给电子等离子体波
    • SBS：激光把能量耦合给离子声波

    因此 SRS 主要涉及电子时间尺度，SBS 主要涉及更慢的离子时间尺度。

    物理图像：三波耦合

    设入射泵浦激光为 \((\omega _0 ,\mathbf{k}_0)\) ，它在等离子体中产生一个微小的密度扰动。这个密度扰动相当于一个“动态光栅”，可以把入射激光散射成另一束电磁波 \((\omega _s ,\mathbf{k}_s)\) 。散射光与原激光拍频，又会进一步驱动这个密度扰动。如果相位关系恰好匹配，就出现正反馈，

    密度扰动→激光散射增强→拍频驱动更强→密度扰动更大

    于是散射光和等离子体波都会指数增长。

    核心就是满足三波共振条件：

    \[ \omega _0 =\omega _s +\omega _p\\ \mathbf{k}_0 =\mathbf{k}_s +\mathbf{k}_p \]

    等离子体密度梯度色散效应

    展宽和压缩

    对于一般纵向密度 \(n_e(z)\) ，在静态、冷、无磁等离子体中，沿传播路径积分局部群速度的倒数即可。这里假设正入射、密度变化足够平缓

    设等离子体范围 \(z_1<z<z_2\) ，电子等离子体频率

    \[ \omega_p^2(z)= \frac{e^2 n_e(z)}{\varepsilon_0m_e} \]

    局部色散关系和群速度为

    \[ k(\omega,z) = \frac{1}{c}\sqrt{\omega^2-\omega_p^2(z)}\\ v_g(\omega,z)= \left( \frac{\partial k}{\partial \omega} \right)^{-1}=c\sqrt{1-\frac{\omega_p^2(z)}{\omega^2}} \]

    从而频率 \(\omega\) 对应的群延迟为

    \[ \tau (\omega) = \int_{z_1}^{z_2} \frac{\mathrm{d}z}{v_g(\omega,z)}=\frac{1}{c} \int_{z_1}^{z_2}\frac{\mathrm{d}z}{\sqrt{1-\omega_p^2(z)/\omega^2}} = \frac{1}{c}\int_{z_1}^{z_2} \left[ 1-\frac{n_e(z)}{n_c(\omega)} \right]^{-1/2} \mathrm{d}z \]

    其中临界密度随频率变化，不能对所有频率都取同一个 \(n_c\) 。

    若考虑一个中心频率为 \(\omega _0\) 的脉冲，则相对于中心频率的延迟为

    \[ \Delta \tau (\omega;\omega _0) = \frac{1}{c} \int_{z_1}^{z_2}\left[ \frac{1}{\sqrt{1-\omega_p^2(z)/\omega ^2}}-\frac{1}{\sqrt{1-\omega_p^2(z)/\omega_0 ^2}} \right] \mathrm{d}z \]

    显见

    \[ \omega >\omega _0 \Longrightarrow \Delta \tau <0 \]

    即高频延迟更小。

    1. 傅里叶脉宽极限

    傅里叶极限脉宽（Fourier-transform-limited pulse duration）是：在给定光谱振幅的条件下，各频率分量的相对相位最合适时，脉冲能够达到的最短持续时间。 对应的脉冲称为变换极限脉冲，简称 TL 脉冲。

    把激光电场写成频率分量的叠加

    \[ E(t)=\frac{1}{2\pi} \int _{-\infty}^{\infty} A(\omega ) \mathrm{e}^{\mathrm{i}\phi(\omega)} \mathrm{e}^{-\mathrm{i}\omega t} \]

    其中 \(A(\omega)\) 决定包含哪些频率、各有多强； \(\phi(\omega)\) 决定这些频率如何在时间上叠加。带宽提供形成短脉冲的可能，谱相位决定这种可能是否实现。

    当谱相位只有常数项和线性项时，

    \[ \phi (\omega ) = \phi _0 +t_0 (\omega -\omega _0) \]

    常数项只改变整体相位，线性项只平移脉冲到达时间，均不展宽包络。此时各频率的群延迟

    \[ \tau _g(\omega ) = \frac{\mathrm{d}\phi}{\mathrm{d}\omega} = t_0 \]

    相同，可以集中形成变换极限脉冲。二阶及更高阶谱相位通常会使不同频率错开到达，导致啁啾、展宽或脉冲结构畸变。

    对于最常见的高斯脉冲，时间带宽积满足

    \[ \Delta t_{\mathrm{FWHM}} \Delta \nu _{} \]

    2. 谱相位

    2.1 频谱和谱相位

    设一个脉冲的频域电场写为

    \[ \tilde{E} (\omega ) = |\tilde{E} (\omega )|\mathrm{e}^{\mathrm{i}\phi(\omega)} \]

    其中 \(|\tilde E(\omega)|\) 是频谱振幅， \(|\tilde E(\omega)|^2\) 称为频谱强度； \(\phi(\omega)\) 就是谱相位。

    时间域电场由逆傅里叶变换得到

    \[ E(t) = \frac{1}{2\pi} \int |\tilde{E} (\omega )|\mathrm{e}^{\mathrm{i}\phi(\omega)}\mathrm{e}^{-\mathrm{i}\omega t} \mathrm{d}\omega \]

    可以说，频谱强度决定“有哪些频率、每种频率有多少”，谱相位决定“这些频率在时间域怎样叠加”。

    两个脉冲可以具有完全相同的频谱强度，却因为谱相位不同而具有不同的脉冲宽度、峰值强度、时间波形、前后沿结构和啁啾等。

    2.2 谱相位的泰勒展开

    在中心频率 \(\omega_0\) 附近，把谱相位展开

    \[ \phi (\omega) = \phi _0 +\phi _1(\omega -\omega _0)+\frac{1}{2}\phi _2(\omega -\omega _0)^2+\frac{1}{6}\phi _3(\omega -\omega _0)^3+\cdots \]

    其中

    \[ \phi_n =\frac{\mathrm{d}\phi}{\mathrm{d}\omega ^n}\Big|_{\omega_0} \]

    不同阶数具有完全不同的物理意义：

    项 名称 单位 主要作用
    \(\phi_0\) 常数谱相位 rad 改变载波包络相位，不改变包络
    \(\phi_1\) 群延迟GD s 整个脉冲在时间轴上平移
    \(\phi_2\) GDD s² 产生线性啁啾和脉冲展宽/压缩
    \(\phi_3\) TOD s³ 产生非对称波形和非线性啁啾
    \(\phi_4\) FOD s⁴ 更复杂的高阶时域畸变

    GDD 通常写成 \(\mathrm{fs}^2,\;\mathrm{as}^2\) 。

    2.3 群延迟

    群延迟定义为

    \[ \tau _g(\omega ) = \frac{\mathrm{d}\phi(\omega)}{\mathrm{d}\omega} \]

    它表示频率 \(\omega\)​ 附近的波包分量经历了多大的时间延迟。例如

    \[ \phi(\omega)=\omega t_0 \]

    对应

    \[ \tau_g(\omega)=t_0 \]

    代入逆傅里叶变换

    \[ E(t) = \int \tilde E_0(\omega) e^{i\omega t_0}e^{-i\omega t} \,\mathrm d\omega = E_0(t-t_0) \]

    所以线性谱相位只把脉冲整体延迟 \(t_0\) ，不改变脉冲宽度。

    2.4 群延迟色散GDD

    群延迟色散定义为

    \[ \mathrm{GDD}(\omega) = \frac{\mathrm{d}\tau _g}{\mathrm{d}\omega} = \frac{\mathrm{d}^2\phi}{\mathrm{d}\omega ^2} \]

    在中心频率附近，常用常数

    \[ \boxed{ \phi_2 = \left. \frac{\mathrm d^2\phi}{\mathrm d\omega^2} \right|_{\omega_0} } \]

    表示元件或传播过程的 GDD。

    如果只保留到二阶，谱相位可以写为

    \[ \phi(\omega)=\phi _0+\phi _1\Omega +\frac{1}{2}\phi _2\Omega ^2,\qquad \Omega =\omega−\omega_0 \]

    则群延迟为

    \[ \boxed{ \tau_g(\omega) = \phi_1+\phi_2\Omega } \]

    这说明 GDD 是“群延迟随频率变化的斜率”。

    • \(\phi_2>0\) ：高频分量延迟更大；
    • \(\phi_2<0\)​ ：高频分量延迟更小。

    2.5 正负GDD与频率到达顺序

    正GDD \(\phi_2>0\) ，此时\(\mathrm{d}\tau_g/\mathrm{d}\omega>0\) ，所以频率越高，群延迟越大，低频先到、高频后到，时间域中通常表现为正啁啾

    \[ \frac{\mathrm d\omega_{\rm inst}}{\mathrm dt}>0 \]

    即脉冲从低频扫向高频。负GDD则反之。不过需要注意：严格的正负啁啾约定还依赖于使用的傅里叶变换符号。

    2.6 “群延迟色散”和“群速度色散”有什么区别

    这两个经常被混用，但严格来说不是同一个量。介质传播常数为

    \[ k(\omega)=\frac{n(\omega)\omega}{c} \]

    将其展开

    \[ k(\omega) = k_0+\beta_1\Omega+\frac12\beta_2\Omega^2 +\frac16\beta_3\Omega^3+\cdots \]

    其中

    \[ \beta_1 = \frac{\mathrm dk}{\mathrm d\omega} = \frac{1}{v_g},\qquad \boxed{ \beta_2 = \frac{\mathrm d^2k}{\mathrm d\omega^2} } \]

    称为群速度色散，GVD。它的单位是 \(\mathrm{s^2/m}\) 或常用的 \(\mathrm{fs^2/mm}\) ，脉冲通过长度\(L\)​ 的均匀介质后，传播谱相位

    \[ \phi_{\rm prop}(\omega)=k(\omega)L \]

    所以

    \[ \tau_g(\omega) = L\frac{\mathrm dk}{\mathrm d\omega} \]

    而总 GDD 为

    \[ \boxed{ \mathrm{GDD} = L\beta_2 } \]

    因此：GVD \(\beta_2\) 是介质单位长度的二阶色散；GDD \(\phi_2\) 是经过整个元件后累计的二阶色散。对于非均匀介质，应写成

    \[ \boxed{ \mathrm{GDD} = \int \beta_2(z)\,\mathrm dz } \]

    群速度、群延迟与 GDD 的区别

    三者的层次是：

    群速度

    \[ v_g(\omega) = \left(\frac{\mathrm dk}{\mathrm d\omega}\right)^{-1} \]

    表示某一窄带波包在介质中的传播速度。

    群延迟

    \[ \tau_g(\omega) = L\frac{\mathrm dk}{\mathrm d\omega} = \frac{L}{v_g(\omega)} \]

    表示该频率附近的波包通过长度 LL 所需的时间。

    群延迟色散

    \[ \mathrm{GDD} = \frac{\mathrm d\tau_g}{\mathrm d\omega} \]

    表示不同频率的群延迟差异有多大。

    可以概括为： \(v_g\) 刻画传播有多快\boxed{ v_g：传播有多快 }τg：传播后晚到了多少\boxed{ \tau_g：传播后晚到了多少 }GDD：不同频率晚到的程度相差多少\boxed{ \mathrm{GDD}：不同频率晚到的程度相差多少 }

    真正导致脉冲展宽、压缩和啁啾变化的不是共同群延迟，而是群延迟对频率的变化，即 GDD 及更高阶色散。

    为什么 GDD 会使脉冲展宽

    假设最初是傅里叶极限脉冲，各频率分量在同一时刻相干叠加。

    如果通过一个具有 GDD 的 $$ \tau_g(\omega) = \tau_0+\phi_2(\omega-\omega_0) $$ 那么不同频率到达不同时间： $$ \Delta\tau_g \simeq \phi_2\Delta\omega $$ 于是原本集中在一起的频率成分沿时间方向散开，脉冲展宽。

    对于傅里叶极限高斯脉冲，加入 GDD 后，强度 FWHM 满足 $$ \boxed{ \tau = \tau_{\rm TL} \sqrt{ 1+ \left( \frac{4\ln2\,\phi_2}{\tau_{\rm TL}^2} \right)^2 } } $$ 其中 \(\tau_{\rm TL}\) 是傅里叶极限强度 FWHM。

    可见对原本无啁啾的脉冲，无论

    \(\phi_2>0\)还是ϕ2<0,\phi_2>0 \quad\text{还是}\quad \phi_2<0,

    只要 ϕ2≠0\phi_2\neq0，都会展宽。正负号只决定频率排列顺序，而脉宽只与 ϕ22\phi_2^2 有关。

    为什么 GDD 也能压缩脉冲

    如果输入脉冲本来已经具有 GDD：

    ϕ2,in≠0,\phi_{2,\rm in}\neq0,

    再通过另一个色散元件，总二阶谱相位为

    ϕ2,tot=ϕ2,in+ϕ2,element\boxed{ \phi_{2,\rm tot} = \phi_{2,\rm in} + \phi_{2,\rm element} }

    若两者异号：

    ϕ2,element≈−ϕ2,in,\phi_{2,\rm element} \approx-\phi_{2,\rm in},

    则

    ϕ2,tot≈0,\phi_{2,\rm tot}\approx0,

    不同频率重新在时间域重合，脉冲压缩至接近傅里叶极限。

    所以同一种介质究竟使脉冲展宽还是压缩，不能只看介质 GDD 的符号，还要看输入脉冲已有的谱相位。

    例如：

    • 傅里叶极限脉冲 + 负 GDD → 展宽并产生负啁啾；
    • 正啁啾脉冲 + 适量负 GDD → 压缩；
    • 正啁啾脉冲 + 过量负 GDD → 先压缩，随后重新展宽为负啁啾。

    瞬时频率与谱相位不是同一个相位

    频域中有谱相位

    ϕ(ω).\phi(\omega).

    时间域电场也可以写成 $$ E(t)=A(t)e^{-i\omega_0t+i\varphi(t)} $$ 这里 φ(t)\varphi(t) 是时间相位。按照这个符号约定，瞬时频率为

    ωinst(t)=ω0−dφdt\boxed{ \omega_{\rm inst}(t) = \omega_0-\frac{\mathrm d\varphi}{\mathrm dt} }

    谱相位和时间相位互相关联，但不能简单地把

    dϕdω\frac{\mathrm d\phi}{\mathrm d\omega}

    称为瞬时频率。正确对应是：

    • 谱相位的一阶导数 → 各频率的群延迟；
    • 时间相位的一阶导数 → 各时刻的瞬时频率。

    对于强啁啾、单调频率扫描的脉冲，可以近似建立

    t≃τg(ω)t\simeq\tau_g(\omega)

    的对应关系：群延迟曲线告诉我们每个频率主要出现在哪个时刻。

    等离子体中的这些量

    对于均匀无碰撞等离子体，

    k(ω)=1cω2−ωp2.k(\omega) = \frac{1}{c} \sqrt{\omega^2-\omega_p^2}.

    传播长度 LL 后的谱相位为

    ϕpl(ω)=Lcω2−ωp2\boxed{ \phi_{\rm pl}(\omega) = \frac{L}{c}\sqrt{\omega^2-\omega_p^2} }

    群延迟为

    τg(ω)=dϕpldω=Lcωω2−ωp2\boxed{ \tau_g(\omega) = \frac{\mathrm d\phi_{\rm pl}}{\mathrm d\omega} = \frac{L}{c} \frac{\omega}{\sqrt{\omega^2-\omega_p^2}} }

    GDD 为

    GDDpl=d2ϕpldω2=−Lωp2c(ω2−ωp2)3/2<0\boxed{ \mathrm{GDD}{\rm pl} = \frac{\mathrm d^2\phi{\rm pl}}{\mathrm d\omega^2} = -\frac{L\omega_p^2} {c(\omega^2-\omega_p^2)^{3/2}} <0 }

    在稀薄等离子体中，

    ωp≪ω,\omega_p\ll\omega,

    有

    ϕpl(ω)≃Lωc−Lωp22cω,\phi_{\rm pl}(\omega) \simeq \frac{L\omega}{c} -\frac{L\omega_p^2}{2c\omega},τg(ω)≃Lc+Lωp22cω2,\tau_g(\omega) \simeq \frac{L}{c} + \frac{L\omega_p^2}{2c\omega^2},GDDpl≃−Lωp2cω3\boxed{ \mathrm{GDD}_{\rm pl} \simeq -\frac{L\omega_p^2}{c\omega^3} }

    因此等离子体中：

    • 低频附加群延迟较大；
    • 高频附加群延迟较小；
    • GDD 为负；
    • 可以补偿正啁啾。

    这正是本文 Fig. 4 的时间压缩机制。

    GDD 与高阶色散的边界

    只用 GDD 描述脉冲，意味着假设群延迟曲线近似为直线：

    τg(ω)≃ϕ1+ϕ2(ω−ω0).\tau_g(\omega) \simeq \phi_1+\phi_2(\omega-\omega_0).

    但一般情况下还有

    τg(ω)=ϕ1+ϕ2Ω+12ϕ3Ω2+16ϕ4Ω3+⋯\tau_g(\omega) = \phi_1 +\phi_2\Omega +\frac12\phi_3\Omega^2 +\frac16\phi_4\Omega^3+\cdots

    如果带宽很宽，或者频率接近等离子体截止频率，群延迟明显偏离直线，就不能只讨论一个 GDD。

    例如等离子体精确群延迟

    τg(ω)=Lcωω2−ωp2\tau_g(\omega) = \frac{L}{c} \frac{\omega}{\sqrt{\omega^2-\omega_p^2}}

    在 ω→ωp+\omega\rightarrow\omega_p^+ 时迅速发散。因此：

    • 高频和低频之间不是简单的线性延迟差；
    • 一个常数 GDD 无法完全补偿；
    • 即使二阶项抵消，高阶谱相位仍会留下旁瓣和非对称波形。

    这也是你之前的“接近临界密度反射”方案与本文稀薄等离子体方案的关键区别：本文主要处在可以用负 GDD 描述的弱色散区；你的模型必须进一步考虑完整的 τg(ω)\tau_g(\omega)、不同频率的反射位置和反射相位。

    最后压缩成一条逻辑链

    E~(ω)=∣E~(ω)∣eiϕ(ω)\tilde E(\omega) = |\tilde E(\omega)|e^{i\phi(\omega)}⇓\Downarrowτg(ω)=dϕdω\tau_g(\omega) = \frac{\mathrm d\phi}{\mathrm d\omega}

    告诉我们不同频率主要在什么时刻到达；

    ⇓\DownarrowGDD=dτgdω=d2ϕdω2\mathrm{GDD} = \frac{\mathrm d\tau_g}{\mathrm d\omega} = \frac{\mathrm d^2\phi}{\mathrm d\omega^2}

    告诉我们群延迟随频率怎样变化；

    ⇓\Downarrow

    若不同频率被拉开，脉冲展宽；若外加 GDD 抵消输入谱相位曲率，脉冲压缩。

    最简洁地区分就是：

    ϕ(ω)：相位本身\boxed{\phi(\omega)：相位本身}τg(ω)：相位斜率\boxed{\tau_g(\omega)：相位斜率}GDD(ω)：相位曲率、群延迟斜率\boxed{\mathrm{GDD}(\omega)：相位曲率、群延迟斜率}β2：单位传播长度上的GDD\boxed{\beta_2：单位传播长度上的GDD}

    谱相位是基本量。输入脉冲已有谱相位，等离子体传播再附加一部分谱相位；总谱相位直接相加。群延迟、GDD 等量则由总谱相位求导得到。

    （由于求导是线性算符，所以各阶衍生量事实上也直接相加）
