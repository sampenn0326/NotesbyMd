    WarpX模拟中的边界条件

    一、边界条件概述

    为了方便量化各个边界条件的表现，可以按照物理功能/目的分为几个大类。

    大类 要实现的目标 典型场边界 典型粒子边界 刻画表现的指标
    周期性 将计算域两侧连接，表示周期重复体系 periodic periodic 跨边界传播的额外误差；振幅、相位连续性；粒子数与电荷守恒
    开放性／出射性 让离开计算区域的扰动尽量不影响域内 PML、Silver–Müller、阻尼区 吸收／出流处理 人工反射率；频率、角度和偏振适用范围；非物理回流、近边界场积累
    反射性／壁面型 实现指定的壁面响应 PEC、PMC 镜面反射、热壁 反射率与相位；场的奇偶性；粒子动量变化；热壁出射分布及能量交换

    二、周期性边界Periodic

    2.1 理论概述

    对于电磁场的周期性边界。设二维 \((x - z)\) 模拟中设横向 \((x)\) 为周期性边界，则它的核心含义是：右端之外的场，由左端内部的场继续延拓；左端之外的场，由右端内部的场继续延拓。在计算中，这通过跨边界的网格数据通信实现。

    从连续理论上，周期性边界当然是

    \[ \mathbf{E}\left( x + L_{x},z,t \right) = \mathbf{E}(x,z,t),\ \ \mathbf{B}\left( x + L_{x},z,t \right) = \mathbf{B}(x,z,t) \]

    在边界节点也就有

    \[ \mathbf{E}\left( x_{\max},z,t \right) = \mathbf{E}\left( x_{\min},z,t \right),\ \ \mathbf{B}\left( x_{\max},z,t \right) = \mathbf{B}\left( x_{\min},z,t \right)\ \ \]

    对于光滑解，导数也要求周期连续

    \[ \partial_{x}\mathbf{E}\left( x_{\max} \right) = \partial_{x}\mathbf{E}\left( x_{\min} \right) \]

    总之，周期边界规定的是两端之间的关系，而没有单独固定两端的场值。

    对于一个沿着 \((+ x)\) 方向传播的真空平面波，只要满足

    \[ k_{x}L_{x} = 2\pi m,\ \ m \in Z \]

    它就是周期系统允许的行波。周期性边界会限制数值离散上存在的波数，但不要求形成驻波。这是因为，周期场可以展开为

    \[ \mathbf{E}(x,z,t) = \sum_{m = - \infty}^{\infty}{\mathbf{E}_{m}(z,t)e^{ik_{m}x}}\ \]

    由于Fourier分量需要满足周期性边界条件，即

    \[ e^{ik_{m}(x + L_{x})} = e^{ik_{m}x} \Longrightarrow e^{ik_{m}L_{x}} = 1 \]

    所以

    \[ k_{m} = \frac{2\pi m}{L_{x}} \]

    所以周期盒允许的横向波数是离散的。但是具体某个 \((k_{m})\)​ 标记的分量可以是行波，也可以是行波和反向行波叠加形成的驻波，这取决于初始条件、激励和后续物理过程。

    2.2 Periodic 在网格上的实现

    设横向分辨

    \[ \Delta x = \frac{L_{x}}{N_{x}} \]

    任何一个网格变量 \((F_{i})\)，其索引为 \((i = 0,1,\cdots,N_{x} - 1)\)。而周期延拓则规定 \(F_{i + N_{x}} = F_{i}\)。例如中心差分

    \[ \left( \partial_{x}F \right)_{i} \cong \frac{F_{i + 1} - F_{i - 1}}{2\Delta x} \]

    在最左端变成

    \[ \left( \partial_{x}F \right)_{0} \cong \frac{F_{1} - F_{N_{x} - 1}}{2\Delta x} \]

    也就是说，左端点的左邻居就是右端最后一个独立网格点。

    实际程序通常在有效网格外保存若干层 ghost/guard cells，预先把对侧数据填进去。这样推进核函数访问相邻数组元素时，读到的就是周期邻居。

    在Yee交错网格上的分量需要分别处理。例如取 \(E_{y}\) 位于 \(x_{i}\)，\(B_{z}\) 位于 \(x_{i + \frac{1}{2}}\)，暂时只考虑 \(x\) 方向的变化，则真空Maxwell方程为

    \[ \partial_{t}B_{z} = - \partial_{x}E_{y},\ \ \partial E_{y} = - c^{2}\partial_{x}B_{z} \]

    对应的常规leapfrog更新是

    \[ B_{z,i + \frac{1}{2}}^{n + \frac{1}{2}} = B_{z,i + \frac{1}{2}}^{n - \frac{1}{2}} - \frac{\Delta t}{\Delta x}\left( E_{y,i + 1}^{n} - E_{y,i}^{n} \right) \]
    \[ E_{y,i}^{n + 1} = E_{y,i}^{n} - c^{2}\frac{\Delta t}{\Delta x}\left( B_{z,i + \frac{1}{2}}^{n + \frac{1}{2}} - B_{z,i - \frac{1}{2}}^{n + \frac{1}{2}} \right) \]

    那么跨边界处，更新最右侧的磁场需要

    \[ E_{y,N_{x}} = E_{y,0} \]

    所以

    \[ B_{z,N_{x} - \frac{1}{2}}^{n + \frac{1}{2}} = B_{z,N_{x} - \frac{1}{2}}^{n - \frac{1}{2}} - \frac{\Delta t}{\Delta x}\left( E_{y,0}^{n} - E_{y,N_{x} - 1}^{n} \right) \]

    更新最左端的电场需要

    \[ B_{z,\frac{- 1}{2}} = B_{z,N_{x} - \frac{1}{2}} \]

    所以

    \[ E_{y,0}^{n + 1} = E_{y,0}^{n} - c^{2}\frac{\Delta t}{\Delta x}\left( B_{z,\frac{1}{2}}^{n + \frac{1}{2}} - B_{z,N_{x} - \frac{1}{2}}^{n + \frac{1}{2}} \right) \]

    这就是周期边界真正进入 Maxwell 推进的具体方式：进入旋度差分所需的跨边界场值。

    初始条件和激励也必须适合周期延拓

    假设在盒内设置一束横向 Gaussian 激光。周期边界会使它代表一列间隔为 \(\ L_{x}\ \) 的重复光束。如果光束在左右边缘已经极弱，这种重复对中心区域的影响可能很小；如果光束接近边缘，则相邻周期副本会参与相互作用。

    还要区分两个问题：两端值不相等：周期延拓存在跳变；两端值相等，但导数不匹配：延拓仍可能不够光滑。例如以盒中心为对称中心的 Gaussian，两端数值相等，但左右导数相反。只有边缘尾部足够小时，这个导数不匹配才可能可以忽略。

    三、开放性/吸收性边界

    3.1 PEC

    3.1.1 基本理论

    PEC 会在壁面产生反射。以二维 \(x - z\) 模拟为例，把 PEC 放在右边界 \(z = L\)。设 \(\mathbf{n}\) 为壁面法向，PEC电磁边界一般写成

    \[ \mathbf{n}\mathbf{\times}\mathbf{E} = 0,\ \ \mathbf{n} \cdot \mathbf{B} = 0 \]

    即

    \[ \mathbf{E}_{\parallel} = 0,\ \ \mathbf{B}_{\bot} = 0 \]

    但导体表面允许存在面电荷和面电流。如果 \(\mathbf{n}\) 从导体指向真空，并采用内部场为零的理想化，则外侧满足

    \[ E_{n} = \frac{\sigma_{s}}{\varepsilon_{0}},\ \ \mathbf{n} \times \mathbf{B} = \mu_{0}\mathbf{K}_{s} \]

    其中 \(\sigma_{s}\) 是面电荷密度，\(\mathbf{K}_{s}\) 是面电流密度。实际上，法向电场和切向磁场往往恰好反映壁面的响应。

    考虑沿 \(+ z\) 正入射、沿 \(x\) 偏振的真空平面波

    \[ \mathbf{E}_{i} = E_{i}\mathbf{e}_{x},\ \mathbf{B}_{i} = \frac{E_{i}}{c}\mathbf{e}_{y} \]

    反射波沿 \(- z\) 传播，因此

    \[ \mathbf{E}_{r} = E_{r}\mathbf{e}_{x},\ \mathbf{B}_{r} = - \frac{E_{r}}{c}\mathbf{e}_{y} \]

    在壁面上，切向总电场必须为零

    \[ E_{i}\left( L,t \right) + E_{r}\left( L,t \right) = 0 \]

    于是

    \[ \boxed{r_{E} = - 1},\ \boxed{R = \mid r_{E} \mid^{2} = 1} \]

    这里的 \(r_{E}\) 是在壁面处、按同一个固定坐标方向定义的电场振幅反射系数。

    对应的磁场却同号相加

    \[ B_{r}\left( L,t \right) = B_{i}\left( L,t \right) \]

    因此壁面切向磁场可以达到入射磁场的两倍。写成完整的驻波更清楚，令 \(\zeta = z - L\)，取

    \[ E_{i} = E_{0}\cos(k\zeta - \omega t),\ E_{r} = - E_{0}\cos(k\zeta + \omega t) \]

    相加得到

    \[ \boxed{E_{x} = 2E_{0}\sin(k\zeta)\sin(\omega t)}\ \qquad \boxed{B_{y} = \frac{2E_{0}}{c}\cos(k\zeta)\cos(\omega t)} \]

    因此

    • 壁面是切向电场的波节；

    • 壁面是切向磁场的波腹；

    • 电场的第一个波腹距壁面为 \(\lambda/4\) ；

    • 相邻电场波节相距 $\lambda/2 $。

    这里确实形成了驻波，因为有实际的入射波和反射波叠加。

    壁面处还有

    \[ S_{n} = \frac{1}{\mu_{0}}(E \times B) \cdot n = 0 \]

    所以固定 PEC 壁面不吸收电磁能量。然而它可以承受动量传递，正入射时的平均辐射压力为

    \[ P_{\text{rad}} = \frac{2I_{i}}{c} \]

    不吸收能量，并不意味着没有辐射压力。

    3.1.2 在网格上的实现

    理想电导体边界（Perfect Electric Conductor, PEC）通过壁面约束与虚拟网格的镜像填充实现。以下考虑二维 \(x-z\) 网格，PEC 壁面位于 \(z=0\)，计算区域为 \(z>0\)。

    对于当前 \(x\) 偏振、沿 \(z\) 传播的问题，主要涉及 \(E_x, E_z, B_y\)。取网格节点为 \((x_i, z_k)\)，其位置为

    \[ E_x: (x_{i+1/2}, z_k) $$ $$ E_z: (x_i, z_{k+1/2}) $$ $$ B_y: (x_{i+1/2}, z_{k+1/2}) \]

    因此，壁面 \(z_0 = 0\) 恰好经过 \(E_x\) 的采样位置，直接施加

    \[ E_{x, i+1/2, 0} = 0 \]

    而 \(E_z\) 和 \(B_y\) 位于壁面两侧的半网格位置，不应把最靠近壁面的内部值强行置零。

    虚拟网格采用奇偶镜像延拓：壁面附近的差分模板可能访问域外数据，因此需要填充虚拟网格。WarpX 使用以下镜像规则

    场分量 壁面条件 跨壁面延拓
    切向电场 \(\mathbf{E}_{\parallel}\) 壁面为零 奇延拓：反号
    法向电场 \(E_{\perp}\) 不强制为零 偶延拓：同号
    切向磁场 \(\mathbf{B}_{\parallel}\) 不强制为零 偶延拓：同号
    法向磁场 \(B_{\perp}\) 壁面为零 奇延拓：反号

    对于当前分量，具体写为

    \[ E_{x, i+1/2, -k} = -E_{x, i+1/2, k}, \qquad k \ge 1, $$ $$ E_{z, i, -k-1/2} = E_{z, i, k+1/2}, \qquad k \ge 0, $$ $$ B_{y, i+1/2, -k-1/2} = B_{y, i+1/2, k+1/2}, \qquad k \ge 0 \]

    这里的镜像按实际空间位置确定：整数节点映射为 \(k \leftrightarrow -k\)，半整数节点映射为 \(k+\frac{1}{2} \leftrightarrow -k-\frac{1}{2}\)。这一区别是交错网格实现的关键。

    边界条件如何进入场推进：以横向均匀的真空平面波为例，Yee 更新式简化为 $$ B_{y, k+1/2}^{n+1/2} = B_{y, k+1/2}^{n-1/2} - \frac{\Delta t}{\Delta z} (E_{x, k+1}^n - E_{x, k}^n), $$

    \[ E_{x, k}^{n+1} = E_{x, k}^n - c^2 \frac{\Delta t}{\Delta z} (B_{y, k+1/2}^{n+1/2} - B_{y, k-1/2}^{n+1/2}) \]

    在壁面 \(k=0\)，磁场偶延拓给出

    \[ B_{y, -1/2} = B_{y, +1/2} \]

    于是电场更新中的磁场差分为零，与

    \[ E_{x, 0} = 0 \]

    相容。实现时仍显式维护壁面零值，并在差分算子需要访问域外数据前填充对应的虚拟网格。域外延拓需要多少格点数，直接而言取决于边界点的差分格式需要几个点，间接方面，则还与电流沉积等有关。

    反射由场推进自然产生：PEC 不需要人为添加一束反射激光。边界约束要求入射场与反射场在壁面满足

    \[ E_{x, \text{inc}} + E_{x, \text{ref}} = 0 \]

    对于真空中的正入射平面波，

    \[ r_E = -1, \qquad r_B = +1 \]

    因此，壁面处切向电场相消、切向磁场相加；理想情况下全部能量反射，法向坡印廷通量为零。

    实现要点： 壁面切向电场置零；虚拟网格按电、磁场各分量的奇偶性填充；反射波由 Maxwell 离散推进自行形成。PEC 是场边界条件，粒子的吸收或反射需要另外设置。

    3.2 PMC

    在场边界的原理和网格实现上，PMC 与 PEC 基本对偶，不必重复展开。 但两者对应的物理反射条件不同，不能当成同一种边界。

    对比项 PEC：理想电导体 PMC：理想磁导体
    壁面零值条件 \(\mathbf E_\parallel=0,\ B_\perp=0\) \(\mathbf B_\parallel=0,\ E_\perp=0\)
    电场镜像延拓 切向奇、法向偶 切向偶、法向奇
    磁场镜像延拓 切向偶、法向奇 切向奇、法向偶
    正入射电场反射系数 \(r_E=-1\) \(r_E=+1\)
    正入射磁场反射系数 \(r_B=+1\) \(r_B=-1\)

    不过，在 Yee 网格上实现时，因为采样位置而稍有差别。

    四、吸收边界

    4.1 PML

    4.1.1 理论：让波进入吸收层时阻抗匹配

    PML（Perfectly Matched Layer，完全匹配层）是包围计算区域的一层人工吸收介质。它的设计同时满足：

    1. 在连续方程层面，物理区域与 PML 的界面匹配，不产生反射。
    2. 波进入 PML 后沿传播方向衰减。

    因此，PML 的关键不是单纯增加阻尼，而是以匹配的方式修改电场和磁场方程。普通有损介质若改变了波阻抗，入口本身就会反射。理想 PML 的无反射性质在离散、有限厚度的计算中不再严格成立。

    考虑 $\(E_x,B_y\)$ 沿 $\(+z\)$ 传播。真空方程为

    \[ \frac{\partial E_x}{\partial t} =-c^2\frac{\partial B_y}{\partial z}, \qquad \frac{\partial B_y}{\partial t} =-\frac{\partial E_x}{\partial z} \]

    在沿 $\(z\)$ 的 PML 中，引入阻尼率 $\(\gamma_z(z)\)$，单位为 $\(\mathrm{s^{-1}}\)$

    \[ \boxed{ \begin{aligned} \frac{\partial E_x}{\partial t}+\gamma_z E_x &=-c^2\frac{\partial B_y}{\partial z},\\ \frac{\partial B_y}{\partial t}+\gamma_z B_y &=-\frac{\partial E_x}{\partial z} \end{aligned}} \]

    电、磁方程采用相同阻尼率，对应通常的匹配条件

    \[ \frac{\sigma_e}{\varepsilon_0} =\frac{\sigma_m}{\mu_0} =\gamma_z \]

    定义左右行特征量

    \[ F_\pm=E_x\pm cB_y \]

    则有

    \[ \boxed{ (\partial_t\pm c\partial_z)F_\pm=-\gamma_zF_\pm } \]

    这个形式直接说明：右行分量在衰减过程中不产生左行分量，反之亦然。 对右行波，

    \[ F_+(z,t) = F_+(z_{\rm in},t-(z-z_{\rm in})/c) \exp\!\left[-\frac1c\int_{z_{\rm in}}^z\gamma_z(\zeta)\,\mathrm d\zeta\right] \]

    若 PML 厚度为 $\(d\)$，外端还有残余反射，其往返衰减的幅值尺度为

    \[ |r_{\rm return}| \sim |r_{\rm end}| \exp\!\left[-\frac{2}{c} \int_0^d\gamma_z(\zeta)\,\mathrm d\zeta\right] \]

    加厚或增强阻尼可以压低外端返回的波，但阻尼变化过陡又可能增加离散界面反射。 这就是 PML 参数需要调节的原因。

    4.1.2 怎样进入二维网格和场推进

    上面的成对阻尼只说明了正入射情况。二维 PML 还要正确处理斜入射，不能直接把全部场分量统一乘一个衰减因子。

    以当前 $\(E_x,E_z,B_y\)$ 分量组为例，分裂场 PML 写成

    \[ B_y=B_y^{(x)}+B_y^{(z)} \]

    并采用

    \[ \boxed{ \begin{aligned} (\partial_t+\gamma_z)E_x &=-c^2\partial_z B_y,\\ (\partial_t+\gamma_x)E_z &=+c^2\partial_x B_y,\\ (\partial_t+\gamma_x)B_y^{(x)} &=+\partial_x E_z,\\ (\partial_t+\gamma_z)B_y^{(z)} &=-\partial_z E_x \end{aligned}} \]

    这里上标表示该分量由哪个方向的旋度项驱动，不是新的物理磁场方向。物理磁场仍是两部分之和。这个结构对应 WarpX 理论文档中的分裂场 PML，经坐标和场变量转换即可得到上述形式。

    假设有一个横向周期、纵向 PML 算例，则

    \[ \gamma_x=0,\qquad \gamma_z= \begin{cases} 0,&\text{物理区域},\\ >0,&\text{纵向 PML} \end{cases} \]

    PML 有实际网格厚度。PML 区域仍使用网格和交错场 $$ E_x:(x_{i+1/2},z_k),\qquad E_z:(x_i,z_{k+1/2}),\qquad B_y:(x_{i+1/2},z_{k+1/2}) $$

    阻尼系数也要在对应位置取值，例如

    \[ \gamma_{z,k}\quad\text{用于 }E_x,\qquad \gamma_{z,k+1/2}\quad\text{用于 }B_y^{(z)} \]

    电磁场相隔半个网格，不能无视位置差异，给它们机械地套同一个数组索引。

    PML 网格还需要与内部网格交换边界数据，保证旋度差分跨越物理区域与 PML 的交界处时有完整模板。

    更新式中增加衰减系数。

    对一般分量

    \[ \partial_tF+\gamma F=S, \]

    若将阻尼项作时间中心离散，

    \[ \frac{F^{n+1}-F^n}{\Delta t} +\gamma\frac{F^{n+1}+F^n}{2} =S^{n+1/2}, \]

    可得

    \[ \boxed{ F^{n+1}=aF^n+bS^{n+1/2}, } \]

    其中

    \[ a=\frac{1-\gamma\Delta t/2}{1+\gamma\Delta t/2}, \qquad b=\frac{\Delta t}{1+\gamma\Delta t/2}. \]

    例如，

    \[ E_{x,k}^{n+1} = a_kE_{x,k}^n -b_kc^2 \frac{B_{y,k+1/2}^{n+1/2}-B_{y,k-1/2}^{n+1/2}}{\Delta z}. \]

    在内部区域 $\(\gamma=0\)$，便恢复普通 Yee 更新

    \[ a=1,\qquad b=\Delta t \]

    这是说明 PML 如何进入推进的一个标准离散形式；具体代码也可采用指数阻尼及算子分裂，应与具体版本实现区分。WarpX 理论文档给出了这种时间中心离散推导。

    阻尼导致的衰减率预测 ：WarpX 26.10 源码中，阻尼系数的空间分布是二次函数。设

    • 网格间距为 \(h=\Delta z\)；
    • 进入 PML 的深度为 \(s\)；
    • 用网格数表示深度 \(u=s/h\)。

    则阻尼率为

    \[ \boxed{\sigma(u)=\frac{4c}{h\delta^2}u^2} \]

    场的阻尼操作使用指数因子：

    \[ \exp[-\sigma(u)\Delta t] \]

    电场节点与磁场半节点分别在各自位置计算这个系数。

    按连续传播近似，忽略离散反射。波以速度 \(c\) 穿过 PML，其单程振幅衰减为

    \[ \frac{A_{\mathrm{out}}}{A_{\mathrm{in}}} = \exp\left[-\int_0^{Nh}\frac{\sigma(s)}{c}\,\mathrm ds\right]. \]

    代入上面的二次分布：

    \[ \boxed{ \frac{A_{\mathrm{out}}}{A_{\mathrm{in}}} \approx \exp\left[-\frac{4N^3}{3\delta^2}\right] } \]

    如果到达最外端的剩余波以振幅反射系数 \(r_{\mathrm{end}}\) 返回，再经历一次阻尼，则入口处的外端回波约为

    \[ \boxed{ |r_{\mathrm{outer}}| \approx |r_{\mathrm{end}}| \exp\left[-\frac{8N^3}{3\delta^2}\right] } \]

    4.1.3 模拟检验

    pml 有两个可以调控的参数 warpx.pml_ncell 和 warpx.pml_delta ，分别对应于阻尼层厚度和衰减系数。

    下降段：经验上的平方反比律

    \[ \eta_R\simeq C\delta^{-2}, \qquad C\approx3.98\times10^{-3} \]

    固定网格时，PML 阻尼系数也随 \(\delta^{-2}\) 缩放。增大 δ，阻尼分布变弱、更平缓，实测回波随之减小。这支持数值匹配误差随阻尼强度减弱的解释；但 \(\eta_R\propto\delta^{-2}\) 目前是数据得到的经验标度，尚不是从离散推进严格推导出的反射定律。

    上升段：外端回波的双程衰减律

    \[ \eta_{\mathrm{outer}} \approx |r_{\mathrm{end}}| \exp\left[-\frac{8N^3}{3\delta^2}\right]. \]

    δ 增大使阻尼减弱。固定厚度 N，更多波到达 PML 外端，反射后再穿过阻尼层返回，所以回波增强。 δ=90、100 数据与这一估计的量级和上升趋势相符。两段之间的最低点，是两种贡献竞争的区域。

    δ 衰减至 1/e 所经历的网格数
    5 约 2.7
    10 约 4.2
    40 约 10.6
    70 约 15.4

    一种解释猜测：小 δ 使衰减集中在少数网格内，可能增大离散反射，离散网格对这种快速衰减的表示可能不够准确；增大 δ 使衰减在更多网格上展开，有利于减小这类误差，但也需要足够的总厚度来保证最终吸收。

    4.1.4 pml域外格点处理

    具体到 Yee、横向均匀、\(E_x/B_y\) 波、右端 PML，可以直接这样看。

    把 PML 最外缘记为 \(z_N\)，省略横向下标，并简写 \(E=E_x,\ B=B_y\)

    场采样位置 是否属于有效网格 如何处理
    \(E_{N-1}\) 是 正常推进并阻尼
    \(B_{N-1/2}\) 是 正常推进并阻尼
    \(E_N\) 是，最外缘节点 仍然推进并阻尼，不强制为零
    \(B_{N+1/2}\) 否，域外 guard cell 没有外侧数据填入，保持初始化的零值
    \(E_{N+1}\) 否 不作为有效场点推进

    这是根据 WarpX 的 PML 场分配及有效网格推进范围整理的。

    ① 更新最后一个有效磁场点

    先暂时不写阻尼，只看旋度推进：

    \[ B_{N-1/2}^{\,\mathrm{new}} = B_{N-1/2}^{\,\mathrm{old}} -\frac{\delta t_B}{\Delta z} \left(E_N-E_{N-1}\right). \]

    这个更新使用两个有效电场点，没有访问域外。

    ② 更新最外缘电场节点

    \[ E_N^{\,\mathrm{new}} = E_N^{\,\mathrm{old}} -c^2\frac{\delta t_E}{\Delta z} \left(B_{N+1/2}-B_{N-1/2}\right). \]

    这里访问了域外磁场点，而它的值是

    \[ B_{N+1/2}=0. \]

    所以实际代入后：

    \[ \boxed{ E_N^{\,\mathrm{new}} = E_N^{\,\mathrm{old}} +c^2\frac{\delta t_E}{\Delta z}B_{N-1/2}. } \]

    程序没有令 \(E_N=0\)，而是在使用“外侧磁场为零”的差分继续更新它。 更新后的 \(E_N\) 又进入下一次 \(B_{N-1/2}\) 的推进，边界影响就这样传回域内。对应旋度操作见 EvolveEPML.cpp 和 EvolveBPML.cpp。

    ③ PML 阻尼另外作用于这些有效场

    上述公式只展开了旋度部分；实际 PML 还对分裂场施加对应位置的阻尼。若抵达最外缘的场已经很小，外侧零值造成的扰动也很小。

    因此，与右端 PEC 的关键区别是

    \[ \begin{array}{ll} \text{PEC：} &E_N=0,\quad B_{N+1/2}=B_{N-1/2};\\[2mm] \text{这里的 PML 外端截断：} &E_N\text{继续推进},\quad B_{N+1/2}=0. \end{array} \]

    这就是网格层面的区别：不是把最外层 \(E、B\) 一起清零，而是最后一个有效电场节点的差分读到了域外的零磁场值。

    4.2 Absorbing_silver_mueller

    **absorbing_silver_mueller 是一种局部出射边界：在边界上要求电场、磁场满足“波向外传播”的关系，从而尽量不生成返回计算域的波。 它没有 PML 那样的有限厚度吸收层。

    对于 \(E_x,B_y\) 平面波，这个关系非常直观。

    1．连续条件：只允许向外传播的分量

    右行波与左行波分别满足

    \[ \text{右行：}\quad E_x=cB_y, \qquad \text{左行：}\quad E_x=-cB_y. \]

    因此：

    边界 希望保留的波 施加的出射关系
    右端 \(z=z_{\max}\) 右行波 \(E_x-cB_y=0\)
    左端 \(z=z_{\min}\) 左行波 \(E_x+cB_y=0\)

    定义

    \[ F_+=\frac{E_x+cB_y}{2},\qquad F_-=\frac{E_x-cB_y}{2}, \]

    它们分别代表右行和左行电场分量。于是边界条件就是

    • 右端令入射分量 \(F_-=0\)；
    • 左端令入射分量 \(F_+=0\)。

    它不是把边界电场设为零，而是允许非零电磁场携带能量流出。 对比 PEC：PEC 要求 \(E_x=0\)，因此必须产生反射波来抵消入射电场。

    2．怎样进入 Yee 推进

    不能简单把某个网格点上的 \(B_y\) 改成 \(E_x/c\)，因为 Yee 格式的电、磁场在空间和时间上交错。

    WarpX 的具体做法是：利用边界电场，更新物理域外最靠内的一层磁场 guard cells。内部电场随后计算磁场旋度时，会使用这些值，从而把出射条件带入推进。

    对于当前二维 \(x\!-\!z\) 设置，涉及 \(B_y\) 的更新可写成

    \[ \boxed{ B_{y,g}^{\rm new} = aB_{y,g}^{\rm old} \pm bE_{x,b}, } \]

    其中右端取正号、左端取负号，并且

    \[ S_z=\frac{c\,\Delta t_{\rm update}}{\Delta z}, \qquad a=\frac{1-S_z}{1+S_z}, \qquad b=\frac{2S_z}{c(1+S_z)}. \]

    这里：

    • \(g\) 表示紧邻物理区域的域外磁场点；
    • \(b\) 下标表示与之相邻的壁面电场点；
    • \(\Delta t_{\rm update}\) 是该边界更新函数接收的推进时间间隔。

    这个式子将旧磁场和当前边界电场组合起来，而不是直接清零，也不是使用 PEC 的奇偶镜像填充。

    3．为什么通常不如 PML 通用

    它使用的是沿边界法向出射的局部电磁场关系。对于横向均匀、正入射真空脉冲，这个连续关系是准确的；但离散后仍可能存在反射。

    斜入射时，波传播方向与边界法向不同，切向场之间的关系会包含入射角因素。简单的法向出射条件不再完全匹配，所以会产生反射。近场、倏逝场也不能直接按法向传播平面波处理。WarpX 文档将它描述为：比 PML 简单、计算成本更低，但吸收效果通常较弱，而且仅支持 Yee 求解器。
