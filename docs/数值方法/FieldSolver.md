## CKC

CKC 是一种**显式、交错网格的有限差分时域方法（FDTD）**。它保留 Yee 方法的时空交错和蛙跳推进，在更新**磁场**时，把每个方向上的差分与其横向相邻位置的差分做加权。这一改动调整了网格对不同方向、不同波长的电磁波的传播速度，也放宽了真空场推进的 CFL 限制。在合适的网格和时间步下，**沿坐标轴传播的真空平面波可以具有精确的离散色散关系**。

（名称中的 CK 指 Cole–Karkkainen，最后的 C 指 Cowan 系数。Cole 和 Karkkainen 的工作建立了扩展差分模板的思路，Cowan 等人研究了非立方网格上如何选择系数和控制传播误差。WarpX 将其实现称为 `ckc`。）

**WarpX 的 RZ 几何不支持 CKC。** 

```
algo.maxwell_solver = ckc
```
