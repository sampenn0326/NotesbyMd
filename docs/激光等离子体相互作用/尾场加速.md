























LWFA存在三个限制

|              限制              |                             解释                             |                      为什么限制电子能量                      |
| :----------------------------: | :----------------------------------------------------------: | :----------------------------------------------------------: |
|    **衍射（diffraction）**     |       激光过了焦点后横向扩展，光斑变大，轴上强度下降。       | 激光即使还携带很多能量，也难以维持足够强的尾场。普通高斯束在自由传播中的典型衍射尺度是瑞利长度 \(z_R=\pi w_0^2/\lambda_0\)，其中 \(w_0\) 是束腰半径。 |
| **泵浦耗尽（pump depletion）** |  激光在驱动等离子体尾场的过程中，把自身能量持续转移给尾场。  | 即使光斑始终保持很小，驱动脉冲也会逐渐失去维持强尾场的能力。 |
|     **失相（dephasing）**      | 相对论电子的速度接近 \(c\)，而常规 LWFA 的尾场相速度通常低于 \(c\)。电子因此会在空泡坐标里逐渐向前滑。 | 电子从空泡后部的加速区滑到接近空泡中心，纵向加速场降到零。再往前滑，就会进入减速区。此时激光仍可能在驱动很强的尾场。 |

**衍射**把光能摊到更大的横截面，降低了轴上强度；**耗尽**则把能量从激光转移给等离子体；**失相**看的是电子与尾场的相对位置，即使尾场本身保持得很好也会发生。







LWFA加速记录

 7.8 GeV

 [Phys. Rev. Lett. 122, 084801 (2019)](https://doi.org/10.1103/PhysRevLett.122.084801).







在传统的LWFA中，近准直的激光脉冲，无论是通过信道还是自引导，都会产生一个以群速度( vg < c)在光速以下传播的有质动力。由此产生的尾流场的相速度等于有质动力的速度。
