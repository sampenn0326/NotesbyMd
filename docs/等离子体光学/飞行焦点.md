##### 1.1.2 等离子体范围和密度分布

理论模型定义

$$
0\le z\le L_p,\qquad L_p=0.61\,\mathrm{mm}=610\,\mu\mathrm m.
$$

该纵向区域之外为真空。PIC 模拟在入口和出口各设置 **$10\,\mu\mathrm m$ 密度坡道**。

|                       参数                        |               数值或说明                |
| :-----------------------------------------------: | :-------------------------------------: |
|                  轴上密度 $n_0$                   |  $1.0\times10^{18}\,\mathrm{cm^{-3}}$   |
|                  轴上归一化密度                   | $n_0/n_{\rm cr}\approx5.7\times10^{-4}$ |
|             通道 matched radius $w_m$             |          $12.5\,\mu\mathrm m$           |
|                  透镜长度 $L_p$                   |           $610\,\mu\mathrm m$           |
|                入口、出口坡道长度                 |          各 $10\,\mu\mathrm m$          |
|                   坡道具体函数                    |               **未说明**                |
| 坡道包含在 $610\,\mu\mathrm m$ 内，还是附加在两端 |             **未明确说明**              |
|         物理通道的径向截断、截断后的密度          |             **未明确说明**              |
|              电子初始温度、动量分布               |             **未明确说明**              |

径向密度是**轴上低、向外二次增加**：

$$
\boxed{
 n_e(r)=n_0+\frac12n_2r^2
}
$$

密度曲率通过 matched radius 确定：

$$
w_m=\left(\frac{8c^2}{\omega_{p2}^2}\right)^{1/4},
\qquad
\omega_{p2}^2=\frac{e^2n_2}{m_e\varepsilon_0}
$$

因此，由原文参数推算：

$$
n_2\approx9.254\times10^{33}\,\mathrm{m^{-5}}
$$

若 $r$ 用 $\mu\mathrm m$、密度用 $\mathrm{cm^{-3}}$，可写为

$$
\boxed{
n_e(r)\approx
10^{18}
+
4.627\times10^{15}
\left(\frac{r}{\mu\mathrm m}\right)^2
\quad\mathrm{cm^{-3}}
}
$$

部分位置的推算值

|        径向位置        |                            密度                            |
| :--------------------: | :--------------------------------------------------------: |
|         $r=0$          |           $1.00\times10^{18}\,\mathrm{cm^{-3}}$            |
| $r=12.5\,\mu\mathrm m$ |           $1.72\times10^{18}\,\mathrm{cm^{-3}}$            |
|  $r=60\,\mu\mathrm m$  |           $1.77\times10^{19}\,\mathrm{cm^{-3}}$            |
| $r=240\,\mu\mathrm m$  | 若抛物线延伸至此，为 $2.68\times10^{20}\,\mathrm{cm^{-3}}$ |

**$w_m=12.5\,\mu\mathrm m$ 是通道的匹配光斑半径，不是等离子体通道边缘。**

##### 1.1.3 入射激光

**基本参数**

|          参数          |                           原文设置                           |
| :--------------------: | :----------------------------------------------------------: |
|  中心波长 $\lambda_0$  | $800\,\mathrm{nm}( \omega_0=2.4\times10^{15}\,\mathrm{rad/s})$ |
|     偏振；横向模式     |          LP；基模Gaussian，$q=\ell=0$，无轨道角动量          |
| 透镜入口光斑半径 $w_I$ |                      $60\,\mu\mathrm m$                      |
| 入口波前曲率半径 $R_I$ |                     $\infty$，即平面波前                     |
|        入射方向        |                       沿 $+z$，正入射                        |

**基本形式**

入口频域复场为

$$
\boxed{
\widetilde E(r,0,\omega)
\propto
A_I(\omega)
\exp\left(-\frac{r^2}{w_I^2}\right)
e^{i\phi_I(\omega)}
}
$$

其中 $A_I(\omega)$ 输入的是四阶 super-Gaussian **频域振幅谱**
$$
\boxed{
A_I(\omega)=
\exp\left\{
-\left[\frac{\tau(\omega-\omega_0)}{2}\right]^4
\right\},
\qquad \tau=21\,\mathrm{fs}
}
$$

二次**频域相位谱**

$$
\boxed{
\phi_I(\omega)
=
\frac12\phi_2(\omega-\omega_0)^2,
\qquad
\phi_2=\frac{\eta\tau^2}{2} =220.5\,\eta\ \mathrm{fs^2}
}
$$

由于

$$
E\propto e^{-r^2/w_I^2},
\qquad
I\propto e^{-2r^2/w_I^2}
$$

所以 $60\,\mu\mathrm m$ 是 **$1/e$ 电场半径，也就是 $1/e^2$ 强度半径**。频域强度谱为 $|A_I|^2$，所以其 FWHM
$$
\Delta\omega
=
\frac4\tau
\left(\frac{\ln2}{2}\right)^{1/4} \qquad  \left(\Delta\omega=1.4\times10^{14}\,\mathrm{rad/s},
\qquad
\Delta\omega/\omega_0\approx0.061 \right)
$$

**改动参数**

文中有改变或扫描的是强度 $a_I$ 和频域相位谱参数 $\eta$ 
$$
a_I=\frac{eE_I}{m_ec\omega_0}
$$

| $a_I$ |                      入射峰值强度                      |
| :---: | :----------------------------------------------------: |
|  0.1  | 约 $2.2\times10^{16}\,\mathrm{W/cm^2}$，按原文比例推算 |
|  0.5  |      原文给出 $5.4\times10^{17}\,\mathrm{W/cm^2}$      |
|  1.0  |        原文约 $2\times10^{18}\,\mathrm{W/cm^2}$        |

不同图使用

|   图   |                       设置                        |
| :----: | :-----------------------------------------------: |
| Fig. 2 |                $a_I=0.5,\ \eta=-5$                |
| Fig. 3 |         $a_I=0.5$，改变啁啾以改变焦点速度         |
| Fig. 5 | 比较 $a_I=0.1,\ 0.5,\ 1.0$，以及 $\eta=-4,-8,-12$ |

原文发现：较短脉冲时 $a_I=0.5$ 的结果较接近线性模型；较长脉冲或 $a_I=1$ 时，等离子体反馈会使脉冲后部明显畸变。

实际时域场需要通过

$$
E_{\rm env}(\xi)
\propto
\int A_I(\omega)e^{i\phi_I(\omega)}
e^{-i(\omega-\omega_0)\xi}\,d\omega,
\qquad
\xi=t-z/c
$$

得到。

以下是按**原文上述频谱和相位数值 Fourier 合成**得到的输入强度 FWHM，**不是原文直接列出的表值**

| $\eta$ | $\phi_2$（$\mathrm{fs^2}$） |     输入强度 FWHM      |
| :----: | :-------------------------: | :--------------------: |
|   0    |              0              | 约 $29.4\,\mathrm{fs}$ |
|   2    |             441             | 约 $41.0\,\mathrm{fs}$ |
|   −4   |            −882             | 约 $107\,\mathrm{fs}$  |
|   −5   |           −1102.5           | 约 $144\,\mathrm{fs}$  |
|   −8   |            −1764            | 约 $246\,\mathrm{fs}$  |
|  −12   |            −2646            | 约 $378\,\mathrm{fs}$  |

因此，Fig. 2 的 $\eta=-5$ 输入脉冲，按该定义约为 **144 fs 强度 FWHM**，而不是 21 fs。
